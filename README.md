# Xpress Delivery — historical product prototype

> **Archive / prototype — not the production Xpress Delivery platform.**

This repository contains a small experimental ordering-flow prototype created around the historical Xpress Delivery API and brand. It is kept public as an implementation artifact, but it should **not** be interpreted as the architecture or source code of the production platform that operated Xpress Delivery.

For the actual product / leadership case study, see:

**[Xpress Delivery — public case study](https://github.com/vizi2000/vizi2000/tree/main/projects/xpress-delivery)**

## What this prototype explored

- low-friction shipment ordering without registration;
- route / price presentation;
- payment-flow concepts;
- a simple responsive web ordering experience;
- integration boundaries around an external delivery API.

## Status

Archived experiment. No active production deployment is represented by this repository.

The historical production Xpress Delivery platform included substantially broader driver, dispatch, operational and enterprise-integration capabilities and is not published here.
